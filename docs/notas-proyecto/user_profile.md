Vicente Lineros M. (vicente.lineros_m@mail.udp.cl) is a Master's student at Universidad Diego Portales working on his thesis: an Adaptive Resource Scheduler for Apache Flink TaskManagers on Kubernetes.

Strong in Java, Bash scripting, and Kubernetes ops. Familiar with Maven, Minikube, WSL2. Working in Spanish but comfortable with English code/docs.

The thesis requires experimental results comparing scheduling strategies (FCFS, BALANCED, LEAST_LOADED, PRIORITY, BANDIT/UCB1, SARSA, ADAPTIVE) across metrics: throughput, stale drop%, source drop%, latency. Results need to be academically defensible with clear differentiation between strategies.
